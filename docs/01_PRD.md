# Refine - 产品需求文档 (PRD)

> 版本: 1.0 | 状态: 草案 | 更新: 2026-02-05

---

## 1. 概述

### 1.1 产品愿景

**让每一次 AI 对话都成为可复用的资产。**

Refine 是一个智能知识复用引擎，从用户与各种 AI 模型的对话中自动提炼知识片段和可执行技能，在用户需要时主动推荐，消除重复提问，放大 AI 对话的价值。

### 1.2 问题陈述

| 问题 | 影响 | 频率 |
|-----|------|------|
| **重复提问** | 用户反复向 AI 问同样或类似的问题，浪费时间和 token | 每周 5-10 次 |
| **知识散落** | 有价值的对话分散在 ChatGPT、Claude、Gemini 等多个平台 | 持续存在 |
| **难以检索** | 想找之前的对话时找不到，只能重新问 | 每周 3-5 次 |
| **无法复用** | 好的 prompt 没有保存，下次还得重新写 | 每次对话 |

### 1.3 目标用户

**主要用户: 重度 AI 用户**

- 开发者（每天使用 AI 辅助编程）
- 内容创作者（使用 AI 生成/优化内容）
- 研究人员（使用 AI 分析和总结）
- 产品经理/设计师（使用 AI 辅助工作流）

**用户特征:**
- 每天与 AI 对话 10+ 次
- 使用多个 AI 平台
- 有知识管理意识
- 愿意为效率付费

### 1.4 成功指标

| 指标 | 定义 | 目标 (6个月) |
|-----|------|-------------|
| **MAU** | 月活跃用户 | 10,000 |
| **知识片段数/用户** | 平均每用户保存的知识数 | 50+ |
| **复用率** | 知识被再次使用的比例 | 30% |
| **推荐点击率** | 自动推荐被采纳的比例 | 15% |
| **NPS** | 净推荐值 | 40+ |

## 2. 用户故事与场景

### 2.1 核心用户故事

```
作为一名开发者
我想要保存我问过 AI 的技术问题和答案
以便下次遇到类似问题时能快速找到，不用重新问
```

```
作为一名内容创作者
我想要把我调试好的 prompt 保存成可复用的技能
以便下次直接填参数使用，不用从头写 prompt
```

```
作为一名重度 AI 用户
我想要在我开始问问题时自动看到相关的历史知识
以便我可以直接复用或在此基础上继续深入
```

### 2.2 关键场景

#### 场景 1: 保存有价值的对话

```
小明在 Claude 上问了一个关于 "Python 异步编程最佳实践" 的问题
得到了非常详细的回答

他点击浏览器插件的 "保存" 按钮
Refine 自动:
  1. 识别这是一个技术知识类对话
  2. 提炼出核心知识点
  3. 抽取代码片段
  4. 打上 tags: python, asyncio, best-practices
  5. 入库并建立向量索引

小明看到提示: "已保存 1 个知识卡片 + 2 个代码片段"
```

#### 场景 2: 自动推荐

```
两周后，小明在 ChatGPT 上开始输入:
"我有一个需要同时请求多个 API 的场景..."

Refine 浏览器插件检测到输入
本地向量搜索匹配到之前保存的 asyncio 知识

侧边栏弹出推荐:
  📄 Python asyncio 最佳实践
  📋 并发请求示例代码 [复制]

小明点击 "复制"，直接粘贴代码，省去重新提问
```

#### 场景 3: 创建可执行技能

```
小红是一名产品经理
她经常让 AI 帮忙写 PRD 的某些章节

她打开 Refine 桌面应用，创建一个新技能:
  名称: "PRD 用户故事生成器"
  参数:
    - 功能名称 (必填)
    - 目标用户 (必填)
    - 核心价值 (必填)
  Prompt 模板:
    "为 {{功能名称}} 生成用户故事，目标用户是 {{目标用户}}..."

下次需要时，她打开悬浮窗，搜索 "PRD"
点击执行，填入参数，生成完整 prompt
一键粘贴到 AI 对话框
```

## 3. 功能需求

### 3.1 功能概览

```
┌─────────────────────────────────────────────────────────────┐
│                        核心功能                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   采集        处理         存储         消费                 │
│   ────        ────         ────         ────                 │
│   浏览器插件   智能提炼     本地数据库    搜索                │
│   手动粘贴    自动分类     向量索引      自动推荐             │
│   API Hook   技能封装     云同步(可选)  技能执行             │
│   文件导入                              导出分享             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 P0 功能 (MVP)

#### F1: 手动保存对话

**描述:** 用户可以手动复制对话内容，粘贴到 Refine 中保存

**验收标准:**
- [ ] 支持粘贴纯文本对话
- [ ] 自动识别问答格式 (Q: / A: 或 Human: / Assistant:)
- [ ] 调用 LLM 自动提炼标题、摘要、标签
- [ ] 生成知识卡片并保存到本地数据库
- [ ] 支持手动编辑保存的内容

#### F2: 知识库浏览

**描述:** 用户可以浏览、搜索、管理已保存的知识

**验收标准:**
- [ ] 列表展示所有知识片段
- [ ] 支持按类型筛选 (知识卡片/技能/代码片段)
- [ ] 支持按标签筛选
- [ ] 支持关键词搜索
- [ ] 支持向量语义搜索
- [ ] 支持查看/编辑/删除

#### F3: 全局快捷搜索

**描述:** 用户可以通过全局快捷键快速搜索知识库

**验收标准:**
- [ ] 全局快捷键 (默认 Cmd+Shift+K) 唤起搜索框
- [ ] 输入即搜索，实时显示结果
- [ ] 支持键盘导航选择
- [ ] 选中后可复制/查看详情
- [ ] Esc 关闭

### 3.3 P1 功能

#### F4: 浏览器插件 - 保存

**描述:** 在 ChatGPT/Claude 等页面一键保存对话

**验收标准:**
- [ ] 支持 ChatGPT、Claude Web
- [ ] 显示 "保存" 按钮
- [ ] 点击后提取当前对话内容
- [ ] 发送到本地 Refine 处理
- [ ] 显示保存成功通知

#### F5: 浏览器插件 - 推荐

**描述:** 在用户输入时自动推荐相关知识

**验收标准:**
- [ ] 监听输入框内容变化
- [ ] 当输入超过 10 个字符时触发搜索
- [ ] 显示侧边栏推荐面板
- [ ] 点击可复制内容到输入框
- [ ] 可关闭/最小化推荐面板

#### F6: 可执行技能

**描述:** 创建和执行带参数的 prompt 模板

**验收标准:**
- [ ] 支持创建新技能
- [ ] 支持定义参数 (文本/选择/多选)
- [ ] 支持 prompt 模板 (使用 {{参数名}} 占位)
- [ ] 执行时显示参数填写表单
- [ ] 生成最终 prompt 并复制到剪贴板

### 3.4 P2 功能

#### F7: 代码片段管理
- 语法高亮显示
- 语言自动检测
- 依赖信息记录

#### F8: CLI 工具
- refine search / add / run / export

#### F9: 云同步
- iCloud / Dropbox / WebDAV 同步

#### F10: 数据导入导出
- 支持导出为 Markdown/JSON
- 支持从其他工具导入

### 3.5 Out of Scope (不做)

- 不做 AI 对话功能 (不替代 ChatGPT/Claude)
- 不做团队协作功能 (MVP 阶段)
- 不做 AI 自动回答功能 (只做知识管理)
- 不做移动端应用 (MVP 阶段)

## 4. 设计规范

### 4.1 设计原则

1. **快速** - 所有操作响应 < 200ms
2. **安静** - 不打扰，推荐可关闭
3. **本地** - 数据本地存储，保护隐私
4. **简洁** - 界面简洁，功能聚焦

## 5. 技术约束

### 5.1 性能要求

| 指标 | 要求 |
|-----|------|
| 搜索响应时间 | < 100ms (本地) |
| 知识提炼时间 | < 5s |
| 应用启动时间 | < 2s |
| 内存占用 | < 200MB |
| 磁盘占用 | < 100MB (不含数据) |

### 5.2 兼容性

| 平台 | 要求 |
|-----|------|
| macOS | 12.0+ |
| Windows | 10+ (后续支持) |
| Chrome | 120+ |
| Firefox | 120+ |
| Edge | 120+ |

### 5.3 安全与隐私

- 所有数据默认存储在本地
- 不收集用户对话内容
- LLM 调用可选择本地模型
- 云同步采用端到端加密

## 6. 发布计划

### 6.1 里程碑

| 阶段 | 内容 | 目标 |
|-----|------|------|
| **Alpha** | CLI + 核心功能 | 验证提炼算法 |
| **Beta** | 桌面应用 + 浏览器插件 | 验证完整流程 |
| **v1.0** | 公开发布 | 获取早期用户 |
| **v1.1** | 云同步 + 技能市场 | 增长 |

### 6.2 MVP 范围

**包含:**
- 手动保存对话
- 智能提炼 (调用 LLM API)
- 本地存储
- 全局搜索
- 桌面应用基础 UI

**不包含:**
- 浏览器插件
- 自动推荐
- 云同步
- CLI

## 7. 风险与依赖

### 7.1 风险

| 风险 | 可能性 | 影响 | 缓解措施 |
|-----|-------|------|---------|
| LLM 提炼质量不稳定 | 中 | 高 | 允许手动编辑，迭代 prompt |
| 向量搜索准确度低 | 中 | 高 | 结合关键词搜索，调优 embedding |
| 浏览器插件审核慢 | 中 | 中 | 提供手动安装方式 |
| 用户不愿意手动保存 | 高 | 高 | 优先做自动推荐，降低操作门槛 |

### 7.2 依赖

| 依赖 | 类型 | 替代方案 |
|-----|------|---------|
| OpenAI API | 外部服务 | Claude API / 本地 Ollama |
| sqlite-vss | 开源库 | faiss |
| Tauri | 框架 | Electron |
