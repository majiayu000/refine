## 4. Refine 差异化定位

### 4.1 核心差异化

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│    Refine 的独特价值主张                                      │
│    ══════════════════════                                   │
│                                                             │
│    1. 专为 AI 对话设计                                       │
│       • 不是通用笔记工具                                      │
│       • 理解 AI 对话的结构和价值                              │
│                                                             │
│    2. 自动采集 + 智能提炼                                    │
│       • 浏览器插件一键保存                                    │
│       • 自动提炼知识卡片、技能、代码片段                       │
│                                                             │
│    3. 主动推荐而非被动搜索                                    │
│       • 在你需要时自动出现                                    │
│       • 减少重复提问                                         │
│                                                             │
│    4. 可执行的技能系统                                       │
│       • 不只是存储，还能执行                                  │
│       • Prompt 模板化复用                                    │
│                                                             │
│    5. 本地优先                                               │
│       • 数据在你手中                                         │
│       • 隐私安全                                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 定位声明

**For** 每天使用 AI 工具的开发者和知识工作者

**Who** 经常遇到重复提问、知识散落、好 prompt 丢失的问题

**Refine is** 一个智能知识复用引擎

**That** 自动从 AI 对话中提炼知识，在需要时主动推荐

**Unlike** Mem.ai、Notion AI 等通用笔记工具

**Our product** 专为 AI 对话设计，支持自动采集、智能提炼、主动推荐和可执行技能

## 5. 竞争策略

### 5.1 短期策略 (6个月)

**聚焦细分市场:**
- 目标: 重度 AI 开发者
- 差异化: 专为 AI 对话 + 本地优先
- 不与 Mem.ai/Notion 正面竞争

**功能优先级:**
1. 做好核心：采集 → 提炼 → 搜索
2. 做透差异化：浏览器插件 + 主动推荐
3. 暂不做：团队协作、移动端

### 5.2 中期策略 (1年)

**扩大护城河:**
- 积累用户知识数据 (本地)
- 优化推荐算法
- 建立技能模板库

**扩展场景:**
- 支持更多 AI 平台
- CLI 集成开发工作流
- API 支持第三方集成

### 5.3 长期愿景

**从工具到平台:**
- 技能市场 (用户分享技能)
- 企业版 (团队知识库)
- AI 对话的 "第二大脑"
