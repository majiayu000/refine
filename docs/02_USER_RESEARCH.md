## 3. 痛点分析

### 3.1 痛点矩阵

```
                    频率高
                      │
         ┌───────────┼───────────┐
         │           │           │
         │  重复提问  │  找不到    │
         │  ★★★★★   │  ★★★★☆   │
   严重   │           │           │   不严重
  ────────┼───────────┼───────────┼────────
         │           │           │
         │ Prompt散落 │  整理耗时  │
         │  ★★★★☆   │  ★★★☆☆   │
         │           │           │
         └───────────┼───────────┘
                     │
                   频率低
```

### 3.2 痛点详情

#### P1: 重复提问同样的问题 (严重度: 5/5)

**描述:**
> "我经常发现自己在问之前问过的问题，尤其是那些不常用但偶尔需要的技术细节。"

**影响:**
- 浪费时间 (平均每次 5-10 分钟)
- 浪费 token/费用
- 挫败感

**频率:** 每周 5-10 次

**当前解决方案:**
- 有意识地记录 → 但不持续
- 搜索聊天记录 → 但找不到
- 重新问一遍 → 接受浪费

**机会:**
- 自动保存有价值对话
- 问问题前提醒相关历史

---

#### P2: 有价值的对话散落各处 (严重度: 4/5)

**描述:**
> "我用 ChatGPT 问代码问题，Claude 写文档，Gemini 分析数据...好的回答分散在各个平台。"

**影响:**
- 需要时找不到
- 无法形成知识体系
- 切换平台成本高

**频率:** 持续存在

**当前解决方案:**
- 手动复制到 Notion → 繁琐，不持续
- 不管它 → 知识丢失

**机会:**
- 统一的知识收集入口
- 跨平台整合

---

#### P3: 好的 Prompt 没有系统管理 (严重度: 4/5)

**描述:**
> "我调试了很久得到一个好用的 prompt，但下次用的时候又找不到了。"

**影响:**
- 重复调试 prompt
- 好的模式无法复用
- 团队无法共享

**频率:** 每周 3-5 次

**当前解决方案:**
- 存在笔记里 → 格式乱，难找
- 存在脑子里 → 会忘

**机会:**
- Prompt 模板管理
- 参数化执行

## 4. 用户访谈指南

### 4.1 访谈大纲

```
总时长: 30 分钟

第一部分: 背景 (5分钟)
─────────────────────
1. 你的工作是什么？日常主要做什么？
2. 你使用 AI 工具（如 ChatGPT、Claude）的频率是？
3. 你主要用 AI 做什么？

第二部分: 行为探索 (15分钟)
─────────────────────
4. 上一次你和 AI 进行了一个特别有价值的对话是什么时候？
   - 那次对话是关于什么的？
   - 你后来有没有再用到那次对话的内容？
   - 你是怎么找到/记住那次内容的？

5. 你有没有遇到过想找之前和 AI 聊过的内容，但找不到的情况？
   - 具体是什么情况？
   - 你最后怎么解决的？
   - 这种情况多久发生一次？

6. 你有没有保存过和 AI 的对话或者好用的 prompt？
   - 你是怎么保存的？
   - 保存在哪里？
   - 后来有用到过吗？

7. 你有没有发现自己在重复问 AI 类似的问题？
   - 举个例子？
   - 为什么会重复问？

第三部分: 需求验证 (10分钟)
─────────────────────
8. 如果有一个工具能自动帮你保存和整理有价值的 AI 对话，
   你觉得有用吗？为什么？

9. 如果在你准备问 AI 问题时，能自动提示你之前问过相关的，
   你觉得怎么样？

10. 你愿意为这样的工具付费吗？大概多少钱/月是合理的？

结束
─────────────────────
11. 还有什么我没问到但你想分享的吗？
12. 你身边有没有类似需求的朋友可以介绍给我？
```

### 4.2 筛选条件

**合格受访者:**
- 每周使用 AI 工具 20 次以上
- 使用至少 2 个 AI 平台
- 有保存/整理 AI 对话的尝试

**排除条件:**
- 仅偶尔使用 AI
- 只用一个平台且满足需求
- 从事 AI 工具开发（避免偏见）

### 4.3 招募渠道

1. 即刻 - AI 相关话题
2. Twitter/X - #ChatGPT #Claude 用户
3. V2EX - 程序员社区
4. 个人关系网络
5. ProductHunt - AI 工具用户

## 5. 竞品用户评价

### 5.1 Mem.ai 用户反馈

**正面:**
> "AI 自动关联笔记的功能很神奇，经常发现意想不到的连接"

> "比 Notion 更适合快速记录想法"

**负面:**
> "搜索有时候找不到我确定存在的内容"

> "没有好的方式导入我在其他地方的笔记"

> "价格有点贵"

### 5.2 Obsidian + AI 插件 用户反馈

**正面:**
> "本地存储让我很安心"

> "插件生态丰富，可以定制"

**负面:**
> "配置太复杂了"

> "AI 功能需要多个插件组合，不够统一"

### 5.3 机会洞察

| 竞品痛点 | Refine 机会 |
|---------|------------|
| 通用笔记不专注 AI 对话 | 专为 AI 对话设计 |
| 需要手动整理 | 自动提炼 |
| 被动搜索 | 主动推荐 |
| 配置复杂 | 开箱即用 |
| 云端存储隐私顾虑 | 本地优先 |
